# ADR-004: SolutionTrace is a causal derivation DAG

**Context:** A simple step-by-step text array is insufficient for complex problem-solving feedback and verification.

**Decision:** SolutionTrace will be implemented as a Causal Derivation Directed Acyclic Graph (DAG) capturing provenance, decisions, and dependencies.

**Consequences:** Richer educational output, ability to track "why" something was calculated.
