# ADR-016: External solvers are adapters/oracles, never hidden didactic answer sources

**Context:** We might use SymPy, SciPy, or other math engines.

**Decision:** External engines are strictly adapters or oracles for the reference solvers. They must never be used to secretly generate answers for the didactic MethodSolver to dress up in fake steps.

**Consequences:** Maintains the integrity of the educational objective.
