# ADR-001: Bender Core is mechanics-agnostic

**Context:** We need a foundation for Bender that can handle a wide variety of structural/mechanics problems without tying itself to a specific domain.

**Decision:** Bender Core must remain completely mechanics-agnostic. It will not know what a Beam, Frame, StressTensor, or Plate is. It only manages identities, tracing, DAGs, etc.

**Consequences:** Easier extensibility. Prevents tight coupling of core libraries to specific problem domains.
