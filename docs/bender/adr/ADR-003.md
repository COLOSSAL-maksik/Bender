# ADR-003: MethodSolver and ReferenceSolver are dependency-isolated

**Context:** We must ensure the educational solver (MethodSolver) does not cheat by peeking at the reference solver's output.

**Decision:** MethodSolver and ReferenceSolver will not import each other or share high-level computational kernels that compromise the independence of their results.

**Consequences:** True pedagogical explanations; strict cross-verification.
