# Bender

Самостоятельный вычислительный проект для генерации и аналитического решения
задач сопротивления материалов, построения эпюр, независимых проверок и
пошаговых объяснений.

В репозитории сохранены каркас проекта, архитектурные проверки BND-00,
основа моделей данных BND-01 и спецификация с тестами эталонных задач Axial1D.
Это исходная основа для разработки. Полноценное приложение и рабочие solvers
ещё не реализованы; наличие исходников и тестов не подтверждает их приёмку.

## Граница готовности

Самостоятельный packaging, lock зависимостей, инфраструктура запуска тестов
и CI ещё не подготовлены. Их bootstrap выполняет Jules после подключения
к этому репозиторию. Поддерживаемого install command, wheel, CLI, API или GUI
пока нет. Окружение Studium с Qt/ORM не подтверждает независимость Bender.

Архитектура предусматривает независимую работу Bender без общей базы данных
со Studium и без обязательного облачного сервера. Первый транспорт будущего
API — локальный JSON-RPC 2.0 over stdio; HTTP и собственный GUI планируются
как последующие этапы. Bender API реализует Jules, клиент Studium — Codex.
Интеграция пока не реализована.

Документы в `docs/bender` сохраняют первоначальный архитектурный snapshot:
упоминания внутреннего subsystem и прямых imports требуют актуализации Jules
при bootstrap. Текущие границы определены этим README и `AGENTS.md`.

## Разработка

Разработку ведёт только владелец при помощи Jules. Внешние PR не входят
в текущий процесс разработки. После initial push изменения проходят через PR
в `main`; второй reviewer не требуется. Обязательные CI checks будут закреплены
отдельно после появления workflows и первых успешных проверок.
